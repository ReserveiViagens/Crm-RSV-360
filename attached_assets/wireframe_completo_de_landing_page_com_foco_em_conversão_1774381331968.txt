Perfeito. Vou te entregar um wireframe completo de landing page com foco em conversão, pensado para tráfego vindo de WhatsApp, Facebook, Instagram, TikTok, Google Ads, Meta Ads e YouTube.

A ideia é esta:

a landing page vira a etapa 1 do funil
sua página atual de calendário vira a etapa 2
o checkout vira a etapa 3

Assim você não joga tráfego frio direto numa tela de decisão.

Objetivo da landing

A landing precisa fazer 5 coisas, nessa ordem:

prender atenção em 3 segundos
mostrar valor e desejo
gerar confiança
ajudar a pessoa a se identificar com uma opção
levar para a página de escolha de data/ingresso
Estrutura ideal do funil

Etapa 1: Landing/Home
Etapa 2: Escolha do parque + data
Etapa 3: Checkout
Etapa 4: Upsell de hotel / combo / passeio

Rotas sugeridas:

/ → landing page
/ingressos → página atual
/ingressos?perfil=familia
/ingressos?perfil=economia
/ingressos?destino=rio-quente
/parque/hot-park
/checkout

Crie uma nova landing page/home page para o projeto existente de venda de ingressos para parques de Caldas Novas e Rio Quente.

Contexto:
- hoje o projeto está entrando direto na página de calendário e escolha de datas
- essa página atual deve continuar existindo, mas passar a ser a etapa 2 do funil
- a nova landing page será a etapa 1 do funil para tráfego vindo de WhatsApp, Facebook, Instagram, TikTok, Google Ads, Meta Ads e YouTube
- o foco da nova página é conversão, desejo, confiança, prova social, CTA forte e melhor UX para tráfego frio
- manter o estilo visual moderno do projeto, mas deixar a interface mais viva, mais emocional e mais persuasiva
- a página atual de calendário deve continuar como rota de compra/seleção

Objetivo:
Criar uma home/landing page que:
- apresente a oferta de forma forte e clara
- gere desejo com visual mais rico
- conduza o usuário até a página de ingressos
- aumente confiança com prova social e benefícios
- tenha CTA para WhatsApp e CTA para ver ingressos
- seja mobile-first
- tenha design com aparência premium e alta conversão
- use React + Tailwind
- use componentes reutilizáveis

Regras obrigatórias:
- não remover a página atual de calendário
- criar uma nova rota principal `/`
- manter a página atual como `/ingressos` ou rota equivalente
- a landing page deve ser a nova entrada principal do projeto
- usar React + Tailwind
- criar layout responsivo
- criar seções reutilizáveis e organizadas
- usar hierarquia visual forte
- usar cards mais vivos
- usar imagens placeholders elegantes se não houver assets reais
- incluir espaço preparado para vídeo hero
- incluir microinterações suaves com Tailwind
- manter performance boa
- não exagerar em efeitos pesados
- design focado em conversão e legibilidade
- texto em português-BR
