# RSV360 - Reservei Viagens

[![CI](https://github.com/ReserveiViagens/Crm-RSV-360/actions/workflows/ci-e2e.yml/badge.svg)](https://github.com/ReserveiViagens/Crm-RSV-360/actions/workflows/ci-e2e.yml)

Sistema de reserva de viagens com CRM integrado.

## Stack

- **Frontend**: React 18 + TypeScript + Vite + TanStack Query v5 + wouter + shadcn/ui
- **Backend**: Node.js + Express + TypeScript (ESM via tsx)
- **Banco**: PostgreSQL + Drizzle ORM
- **Testes**: Playwright (E2E)

## Desenvolvimento

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build
npm run build

# Testes E2E
npm run e2e

# Verificar tipos
npm run check
```

## Estrutura do Projeto

- `client/` - Frontend React
- `server/` - Backend Express
- `shared/` - Tipos compartilhados
- `tests/` - Testes E2E
- `docs/` - Documentação</content>
