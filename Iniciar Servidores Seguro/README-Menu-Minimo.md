# Menu de Servidores RSV360 - Versão Mínima

Este menu é a versão mais curta para uso rápido.

## O que ele faz

- iniciar uma stack
- parar uma stack
- limpar portas e processos temporários
- mostrar status das portas
- mostrar healthchecks básicos

## Como usar

1. Abra `Abrir_Menu_Rapido.bat`
2. Escolha a ação
3. Se escolher iniciar ou parar, informe a stack:
   - `pms`
   - `ecosystem`
   - `crm`

## Quando usar

Use esta versão quando você quiser ir direto ao ponto sem o fluxo guiado do menu completo.
